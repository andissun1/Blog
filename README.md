# Блог

Сайт для ведения блога с серверной частью.

## Установка
Приложение рассчитано на запуск локальных серверов для клиента, сервера и БД.   
Запускаем конейнер с mongoDB:

```
docker run -d \
  --name mongo \
  -p 27017:27017 \
  -v mongo_data:/data/db \
  -e MONGO_INITDB_DATABASE=testdb \
  -e MONGO_INITDB_ROOT_USERNAME=user \
  -e MONGO_INITDB_ROOT_PASSWORD=mongopass \
  mongo:latest

```
Запускаем сервер (порт 3001):
```
cd server
npm run dev
```
Запускаем клиент (порт 3000):
```
cd client
npm run dev
```

## Функциоанл
В приложении 3 сущности: пользователи, посты, комментарии.  

**Действия с пользователми:** чтение, создание, удаление  
**Действия с постами:** чтение, создание, редактирование, удаление  
**Действия с комментариями:** чтение, создание, удаление  
Есть также поиск с пагинацией по заголовкам постов

Для нового пользователя присваивается роль админа, сделано для удобства оценки. Если хочется переключиться на другую роль, то можно создать второй аккаунт и ему присвоить роль пользователя или модератора. Роли меняются на [странице пользователей](http://localhost:3000/users)
