# Блог

Сайт для ведения блога с серверной частью.

## Установка
Приложение доступно для локального запуска. Запустим клиент, сервер и БД при помощи docker-compose. 
Создаем в корне проекта env файл: 
```
DB_CONNECTION_STRING=mongodb://user:mongopass@myMongo:27017/blog_app?authSource=admin
SECRET_JWT=test
```
Поднимаем локально на 80 порту командой:

```
docker compose up --build
```
Готово! Вы великолепны!


## Функциоанл
В приложении 3 сущности: пользователи, посты, комментарии.  

**Действия с пользователями:** удаление аккаунта, смена роли, просмотр списка пользователей.  
**Действия с постами:** чтение, создание, редактирование, удаление.  
**Действия с комментариями:** чтение, создание, удаление.  

Для нового пользователя присваивается роль админа, сделано для удобства оценки. Если интересно переключиться на другую роль, то можно создать второй аккаунт и ему присвоить роль пользователя или модератора. Роли меняются на [странице пользователей](http://localhost:3000/users)
